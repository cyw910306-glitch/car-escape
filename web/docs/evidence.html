4공모전 개발 범위와의 대응

공지 항목카 이스케이프
공개된 SDK 만 사용Pleos Vehicle SDK 2.3.2 를 씁니다. 기어, 속도, 충전 상태, 목표 충전량, 주행 제한은 Android Automotive 표준 android.car API 로 읽습니다. Pleos 의 기어 API 가 사용 중단으로 표시되어 표준 속성을 쓰도록 안내하고 있고, 주행 제한은 Pleos 주행 규제 개발 가이드가 CarUxRestrictionsManager 를 쓰도록 안내합니다
LLM SDK 미제공LLM 을 쓰지 않습니다. 이야기, 지시문, 힌트는 모두 앱에 들어 있는 문장입니다
차량 마이크 음성의 외부 인식 금지마이크와 음성 인식을 쓰지 않습니다. 권한도 없습니다
Android API 28 이상, Gradle 8.0 이상, KotlinminSdk 28, Gradle 8.14.3, Kotlin 2.3.21
2차 발표는 에뮬레이터 구동 시연car 빌드와 Virtual Console 로 15분, 30분 편을 완주한 기록이 있습니다

5확인하지 못해 계획이나 가정으로 둔 것

  • 실차 실행 전부.
  • 안전벨트와 탑승 좌석 신호: 에뮬레이터 Virtual Console 에 조작 카드가 없어 debug 빌드의 시연 패널로만 확인했습니다.
  • 조수석, 2열 창문, 창문 잠금, 주행 모드: 코드는 있으나 에뮬레이터에서 조작해 보지 않았습니다.
  • 속도만으로의 차단: 코드는 있으나 실기에서 속도만 바꿔 확인하지 않았습니다.
  • 17형 이외 화면: 스냅샷 테스트와 웹 체험판으로만 확인했습니다.
  • Pleos TextToSpeech SDK: 쓰지 않았습니다. 지금 음성은 Android 표준 TextToSpeech 입니다.
