3자체 제작물

항목만든 방법
3D 차 모델과 차 그림공개된 제원 치수를 바탕으로 Blender 에서 직접 모델링한 양식화 모델입니다. 공식 사진은 형태를 참고하는 데만 썼고, 공식 이미지나 3D 자산은 들어 있지 않습니다. 제조사 로고와 엠블럼은 넣지 않았습니다
화면 이미지이 자료의 화면 이미지는 모두 자체 앱의 캡처입니다. 웹 체험판을 헤드리스 브라우저로 캡처한 것과 Android 화면 스냅샷(Paparazzi) 두 종류입니다
웹 체험판의 차량 화면틀상태바, 주행 정보 화면, 하단 바는 Pleos Connect Emulator 화면의 치수를 재서 직접 그린 모사입니다. 아이콘은 직접 그린 SVG 이고 공식 UI 이미지를 쓰지 않았습니다
앱 아이콘, 퍼즐 그림, 스티커코드(Compose Canvas, SVG)로 직접 그렸습니다
이야기, 지시문, 힌트직접 썼습니다
웹 체험판 음성오픈소스 음성 합성 모델 VoxCPM2(OpenBMB, Apache License 2.0)로 만든 합성 음성입니다. 목소리는 설명 문장으로 만든 것이며 실존 인물의 목소리가 아닙니다. Android 앱은 기기의 TTS 엔진으로 읽습니다
효과음Android 는 시스템 톤(ToneGenerator), 웹은 코드로 합성한 소리입니다. 음원 파일을 쓰지 않습니다

4참고한 공식 문서

  • Pleos Playground 개발 문서: Vehicle SDK, 주행 규제 개발 가이드, 디자인 가이드(레이아웃, 색, 타이포그래피, 컴포넌트), 폼팩터 테스트 가이드, Virtual Console 가이드
  • Pleos Connect Emulator v2.1.0: 폼팩터 콘솔의 앱 창 크기 표시값, 시스템 화면의 치수
  • 공모전 공식 안내 페이지의 제출 규정과 심사 기준

위 문서의 문장이나 그림을 이 자료에 옮겨 싣지 않았습니다. 수치(앱 창 dp, 대비 기준, 글자 크기 기준)만 인용했습니다.
